# 《发哨子的人》与艾芬采访：首轮来源可行性审计

**2026-10-29｜第一轮定点审计｜研究初筛，不建公共网页、不公布私人原帖、不视为独立人类复核。**

## 一、适合研究的对象

不是“又一个疫情谣言故事”，而是**报道的内容、公开发表、平台不可见、再传播、格式变换和档案幸存的完整生命周期**。与上海“政策预测—官方标签—执行”和李文亮“官方标签—书面训诫—正式撤销”构成第三个不同的权力机制：**平台可见性与集体档案抵抗**。

## 三、目前观察与政治解释的分界

- **观察：** 同期媒体对原文从主账号消失、转载遭限制及变形传播有记录；CDT保存了若干版本入口。
- **合理解释：** 政治敏感采访遭可见性限制后，公众通过改变编码和载体来维持传播；这具有表达权利与国家/平台信息控制研究价值。
- **暂不可证实：** 具体审查命令发出者、哪次删除由中央或地方哪级官员直接下令、原刊删除的准确分钟、全部变体的去留及传播人数。
- **特定混淆：** 404、平台违规提示、编辑自撤、原链接变更、账号限制、网络故障，应有不同证据等级。不能以“今天打不开”作为“2020年当日遭政治指令删除”的直接证据。

## 四、可执行的最小下一步：只做高增益原件审计

1. 从被引用的原始微信 URL 或存档元数据定位《人物》**首发载体**；检查有无2020-03-10带日期的抓取/缓存。
2. 仅取4组**短片段或文本指纹**做差异：采访导语、医院纪律约谈、传播源头的因果叙述、结尾；不把受版权保护的采访全文重新托管。
3. 将每个传播版本标注成 verbatim / excerpt / transformation / attributed retyping / unverifiable；并保留“能查到的最早日期”。
4. 对任何删文主张单独登记实际证据：原始平台错误画面截图（含捕获时间）或当时独立观察者的记录；与后期回忆分别列示。
5. 如果无法获得原载体的版本证据，**停在来源生态与文本幸存分析**，不写“谁下令、何时删除”式定论。

## 五、出版与项目定位决定

**FEASIBLE FOR BOUNDED PILOT；NOT YET PUBLICATION-READY。** 最值得做的原创研究不是翻译艾芬全文，而是展示可核验的**版本关系图**和“文本仍在传播、原载体是否可访问”的分层证据。它与现有六个时钟共享 provenance graph、as-of snapshots、claim status、source independence 与版次时间的结构资产，但单独保存数据与伦理边界。
