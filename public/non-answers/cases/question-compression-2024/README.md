## 证据边界

1. **2024-05-08**：彭博社完整记者提问包含「是否公布音频／何时／文字稿人名」三个可区分的要求。当天所查央视新闻简讯没有显式呈现后两个要求。
2. 新闻客户端网页标注17:34，外交部官网完整实录标注18:20。**不能声称前者直接从后者的网页删去文字**；只能对照公开文本内容。
3. 答复引用此前的使馆说明，未直接给出所问的未来公布时间和人名。部分媒体已在此前接触音频片段；不能宣称中方从未提供任何材料。
4. 新闻摘要有篇幅限制，省略问题不证明故意误导；目前没有读者理解效果数据。
5. 2025-09-22 央视新闻存在保留多项记者提问的不同报道，展示反例而非统计上普遍的编辑倾向。
6. 不裁定中菲协议或录音真伪，不推断相关机构的内心动机；所有问题卡是**明确标注的归纳性意译**。
