5. 2025-09-22 央视新闻存在保留多项记者提问的不同报道，展示反例而非统计上普遍的编辑倾向。
6. 不裁定中菲协议或录音真伪，不推断相关机构的内心动机；所有问题卡是**明确标注的归纳性意译**。
