## 内容与交互

- `index.html`：逐篇撰写的简体、繁体、英文版本。先呈现媒体简讯，再揭示完整记者提问；逐项检查三个信息需求的答复覆盖度。
- `evidence.json`：来源 S01–S04、三项需求、来源链接及结论边界。
- `../../index.html`：主文章中的三语入口，保留2023年青年失业率既有案例。
- `scripts/check-non-answers-p13.mjs`：针对构建产物的三语、交互、来源、路径、移动端与桌面端测试，并保存截图。由专用 GitHub Actions 工作流执行。

## 必须保留的证据边界

1. 2024-05-08 彭博社完整提问涉及三项信息：是否公开录音、何时公开、文字稿隐去的人名。所查央视新闻简讯只保留了较简化的问题，未明示另外两项。
2. 央视新闻转载页标注17:34，外交部官网完整实录标注18:20；仅可证明两份公开文本范围不同，**不能推断前者从后者网页删改了文字，或存在明确稿件复制链**。
3. 同期已有向部分媒体播放音频片段、传播文字稿的报道，不得宣称从未披露任何材料。
4. 摘编可能源于篇幅、编辑目的或其他原因；**不能仅凭本文推断动机或已观察到的受众误导效果**。
5. 2025-09-22 央视新闻另有完整保留多个记者问题的报道，是有意义的反向样本，不能由单一案例外推所有媒体。
6. 本案例不裁定录音及中菲争议具体事实真伪。互动中的问句卡片是标注为归纳性意译的摘要。
