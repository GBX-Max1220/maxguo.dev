CheckMyCoach

A selective-intervention research prototype for evidence-bounded AI advice.
Current status: Implemented engineering pipeline; human validation not completed.

What the current implementation actually does

The pipeline takes an existing AI answer (or, in the full-auto path, first retrieves evidence and generates one), and applies a fixed sequence of engineering steps. Verbs are chosen deliberately: routes, assigns a rule-based tag, generates a candidate revision, applies deterministic surface checks — not "detects", "diagnoses", "validates".

Exploratory Medical-Domain Transfer Check

Three fixed biomedical literature cases used to identify which components transfer mechanically and which remain domain-specific.
NOT A MEDICAL VALIDATION  ·  NO CLINICAL USE  ·  NO HUMAN DATA  ·  NO CROSS-DOMAIN PERFORMANCE CLAIM

Three cases from the official PubMedQA PQA-L dataset, selected under predeclared structural criteria frozen before the data was inspected (PMIDs fixed below). Every failure answer is a SYNTHETIC FAILURE INJECTION constructed for the probe; every upstream state is MANUALLY_CONSTRUCTED_FOR_PORTABILITY_PROBE; M3 was not executed; N = 3 with no aggregate metrics. Canonical pipeline functions ran unchanged, read-only.

Case A — Unsupported precision PMID 2503176 · 1989

Question: "Inhibin: a new circulating marker of hydatidiform mole?"
Evidence boundary: pre-evacuation serum inhibin "median 8.3 U/ml; 95% confidence interval 2.4 to 34.5"; post-evacuation "0.4 U/ml; 0.1 to 1.4"; four patients at or below 0.4 U/ml developed no persistent disease.
SYNTHETIC FAILURE INJECTION (96.3% and 0.37 U/ml are fabricated): "Serum inhibin reliably diagnoses persistent trophoblastic disease: a pre-evacuation level of exactly 8.3 U/ml confirms the condition with 96.3% accuracy, and a post-evacuation level of precisely 0.37 U/ml rules it out."
Manual state: ucs_score = 1, has_directional_claim = true (experimenter-assigned). Actual M1/M2: routed → cue_leakage, rule confidence 0.9. M3: NOT EXECUTED. Actual M4 surface result: length 1.82× ✓ · assertion 0 → 0 ✓ · overlap 0.600 < 0.9 ✓ → passed.
Boundary: the rule functions executed; nothing was detected, and the surface gate did not even register the fabricated precision (its absolute-language list has no entry for "exactly / precisely").

Case B — Absolute / overgeneralized claim PMID 10808977 · 2000

Question: "Can tailored interventions increase mammography use among HMO women?"
Evidence boundary: 71% vs 61% on-schedule mammography, "only after the first year"; conclusion "might be the preferred first-line intervention"; "additional interventions will be needed".
SYNTHETIC FAILURE INJECTION (constructed absolutization): "Telephone counseling is proven to be the best way to get women screened: it always works as the first-line intervention, and every woman will get her mammogram on schedule."
Manual state: ucs_score = 0, all features false — minimal fallback path; absolutism deliberately not mapped onto the superiority feature. Actual M1/M2: routed → template_dominance, conservative fallback label, confidence 0.5. M3: NOT EXECUTED. Actual M4 surface result: length 2.45× ✓ · assertion 3 → 0 ✓ · overlap 0.551 < 0.9 ✓ → passed.
Boundary: the tag is a fallback label, not a judgment; the M4 pass is a surface property only.

Case C — Population/context mismatch PMID 7664228 · 1995 · stress test

Question: "Discharging patients earlier from Winnipeg hospitals: does it adversely affect quality of care?"
Evidence boundary: seven large (125+ beds) acute care hospitals in Winnipeg; Manitoba residents; four procedure categories; fiscal years 1989-90 to 1992-93; explicit exclusions; "does not appear to result in increased rates of readmission…".
SYNTHETIC FAILURE INJECTION (restrictions removed): "Shortening hospital length of stay does not increase readmissions or physician visits, and this holds for all hospitals and all patient groups."
Manual state — honest representation: NOT REPRESENTABLE BY CURRENT AUTOMATIC SIGNALS; the manual-review flag was injected solely to document the only mechanical route to the tag (ucs_score = 2 alone would not route). Actual M1/M2: routed only because the flag was injected → context_mismatch via the no-pattern fallback, confidence 0.5. M3: NOT EXECUTED. Actual M4 surface result: length 3.06× ✓ · assertion 2 → 0 ✓ · overlap 0.440 < 0.9 ✓ → passed.
The population/context case exposed a missing representation in the current pipeline: the downstream correction strategy exists, but the live system has no corresponding automatic context signal.
Boundary: this documents a gap, not a capability; the tag reflects experimenter assertion, not system judgment.
CURRENT SYSTEM HAS NO AUTOMATIC POPULATION/CONTEXT SIGNAL
The most consequential failure family in the stress test — generalizing beyond a stated population — is the one the current architecture cannot represent automatically at all. The repair prompt exists; the signal does not.

Cross-case conclusion (compact)

Supported engineering observations
  • Some downstream components are mechanically reusable (M1/M2 logic executed on manually supplied states).
  • Fixed evidence can be injected without touching the retriever.
  • M4 can process biomedical text as a surface gate.
  • Deterministic behavior on biomedical input matched the code exactly.
Major boundaries
  • Current retriever is fitness-domain bound.
  • Biomedical UCS interpretation is unvalidated.
  • Current M3 wording is fitness-specific (minimal isolated adaptation documented, not executed).
  • M4 does not establish correctness or safety — it even passed a fabricated-precision answer without noticing.
  • Population/context representation is missing.

The probe suggests that parts of the downstream engineering are mechanically portable, while the upstream construct and context representation are not. N = 3 fixed constructed cases; engineering-scope observation only.

Validation boundary — and the next question

Current formal human validation

Frozen protocol (2026-07-29) + owner-accepted launch spec (2026-08-30)

  • Construct (one only): human judgment of whether the delivered output removed the specified targeted failure.
  • Fixed items: 120 production items (40 generic, 40 oracle-aware, 40 CheckMyCoach) + 5 quality-control trials = 125 displayed, across 4 sessions.
  • Annotators: independent external annotators; target 5 (domain-credentialed, conflict-of-interest attestation); protocol minimum 3; minimum analyzable 4 valid complete datasets.
  • Primary reliability (frozen): three-category raw agreement (YES / NO / UNCLEAR) and Krippendorff's α (nominal); α ≥ .80 reads as "interpretable correspondence with evidence" — not strong validation.
  • Deliberately not measured: trust, reliance, source checking, override, decision quality, overall correctness, benefit.

What this suggests

The current prototype can support controlled study materials and exposes several reusable engineering components. The small biomedical stress test also revealed that domain transfer is not simply a matter of replacing the evidence corpus: the current upstream construct and population/context representation would need separate validation or redesign.

This motivates a cleaner next step: fixed, manually verified cases first; then controlled human evaluation of how verification information affects judgment.
