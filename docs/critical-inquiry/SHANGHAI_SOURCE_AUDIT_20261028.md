# 上海“封城”传言：来源与时间核验备忘录

内部审阅稿 · 2026-10-28 · 对应案例 `shanghai-lockdown-2022`

## 研究问题

公众在高度不确定的公共卫生政策环境中传播一项未来政策预测时，公共机关如何区分 **尚无证据支持的预测、实际虚假陈述、未经授权的消息来源归属** 与 **涉嫌违法的传播行为**？若后来推出部分相似的政策，应如何重新审查此前的真假判断及程序？

这是一项关于公权力、事实定性和政策不确定性的批判性研究，不以“谣言后来完全成真”作为预设。

## 原子命题和时间逻辑

1. **具体传言：** “督查组到上海后全市封城7天”——3月22日晚已有公开转述；原始发布帖仍缺。
2. **官方公开判断：** 3月22日晚和23日有关部门否认具体封城传言——这本身是可考证的行政传播行为，而不是关于内部政策永不变化的保证。
3. **警方程序：** 3月23日立案侦查——应从内容真实性、证据条件、法律适用、行政/刑事程序与比例原则分别评价。
4. **后续政策：** 3月27日正式宣布分区分批封控筛查——与此前“大规模封控”的广义预测存在主题重叠，但与“全市同时封闭7天”的细节并不一致。
5. **回溯限制：** 不能将3月27日的新证据当作3月22日已知的事实，也不能把3月22日预测的不确定性自动当成对任何执法行为的充分正当化。

## 公开发布前必须解决

- 找到更接近原始网络传播的同期截图、发帖记录和文档链，并核实不同版本是不是由相同作者发布。
- 查询涉及两人的后续公开司法资料；如无法获取，继续准确使用“曾被立案侦查”而非“已定罪”等词。
- 将官方公告的**计划时长**与各地**实际执行时长**分开，不能以后者替代前者，亦不可反过来。
- 进行第二位研究者独立复核，不以再次调用同一个模型替代人类盲审。
- 保留所有版本、公开更正和对普通传播者隐私的最小化处理。

## 可写出的批判性结论（目前仅为问题，不是经验证的判决）

**当公共机关能够对未来政策预测公开定性，并将部分传播行为纳入刑事侦查程序时，公众有理由要求更清楚地了解：事实判断的证据阈值是什么，什么属于未经证实，什么属于已证伪，哪些纠错和申诉渠道可用。**

这一追问不依赖“传言全部准确”的事后叙事，也不要求研究者对任何未经证实的政治动机作出断言。
