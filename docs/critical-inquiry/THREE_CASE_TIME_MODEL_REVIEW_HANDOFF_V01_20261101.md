# 《言说的边界》｜三案例时间模型：独立审阅与出版决策

**研究移交包 v0.1 · 2026-11-01 · Draft PR #29 · NOT FOR PUBLICATION**

## 核心研究身份

研究的不只是“某句话是否被封杀”，而是权威对公共解释施加何种影响：标签如何出现、平台和网页入口如何变化、后来材料何时披露、正式纠错能否被追踪。三个研究案例的法律对象和材料结构并不等同，不能把“发生过某种限制”的既定判断当成模型训练标签。

## 两个时间概念

- `event_at`：事件发生或被后来材料指称发生的时刻；有些事件只有日期，使用日终下界，而非伪造具体分钟。
- `observed_at`：本登记首次用于历史视图的同期媒体发表时刻或 Wayback 捕获时刻。对日期不精确的政策公报，保守落在当天 23:59:59。
- `observation_basis`：区分 contemporaneous report、official notice、archive capture 和 retrospective disclosure。
- `source_refs[].lineage_id`：同一声明的多个转载或同一站点的两个版本不能被当作多个独立事实来源。
- 当 `event_at` 早于截点但 `observed_at` 晚于截点时，相关内容只可显示在**单独的事后材料层**，不能进入“截至此时”的主体列表。

这里的历史可见性是“**已登记来源支持的有限可观察状态**”，不是某个日期所有人实际知道什么的调查，更不是对社会平均知情程度的推断。原始数据包含后来的事实，即使 UI 隐藏它们也**不是保密隔离**；该时间过滤只用于防止阅读上的后见混淆。

## 不等价案例的比较伦理

1. 李文亮的正式纠错有撤销训诫和警员处分的公开记录，但最早的8人公告不能无条件定点指向李的所有行为；“训诫”、“处罚”、“纪律处分”的对象不同。
2. 上海警方通报的是立案，不是定罪；当时关于未来政策的7天和4天说法属于不同命题。3月27政策的两段原计划有两小时重叠，但后来政策变化不能反证或证成早先的每一个具体谣言。
3. 艾芬案的核心是不同存档载体的可见性和版本状态；CDT的后来指令披露没有原始签发／送达／执行链。新闻首页自然轮替是链接缺失的未排除竞争解释。

## 自动化验收

- `node --test scripts/critical-visibility-core.test.mjs`：对数据合法性、来源血缘、日期顺序、跨日期未来泄漏、档案捕获时间一致性与错误输入做回归测试。
- `node scripts/build-critical-visibility-prototype.mjs`：只能写到 `.astro/critical-inquiry-research/three-case-time-machine.html`，不在 `src/pages` 下构建任何正式路由。
- `node scripts/check-three-case-time-machine.mjs`：依赖 Playwright 的桌面1440px、手机390px测试，验证三案切换、后见层、无请求、无横向溢出与截图。
- GitHub Actions 对应本 PR 的 `.github/workflows/critical-inquiry-three-case.yml`；保存离线 HTML 与手机/桌面 QA 图片为短期 artifacts。

**CI 成功的边界：**只能表明映射数据、程序约束和界面行为达到本协议要求，不能替代原始网页/存档的独立历史验证，也不能使草稿获得发表许可。

## 方法复用的下一阶段

**优先事项是提升可迁移性，而非再造大型平台。**

下一轮可将原 PR #23 离线双案例页面的有价值编辑文案/交互模式与本 PR 的结构化 schema 对照，逐项保留最有用的设计，而不是合并其硬编码历史叙述。之后选择一个新的、来源数据结构不同的案例（例如丰县）做 schema 压力测试，检验“多时钟+来源依赖”是否真正能迁移。

《正确的废话》的话语分析与社会时间自主权项目可以共享审阅、引用和前端组件，但不应被强制压入刑事标签/存档可见性这一套事件数据结构。
