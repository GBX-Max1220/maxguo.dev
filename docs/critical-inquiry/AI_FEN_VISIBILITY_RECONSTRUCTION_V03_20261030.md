# 《发哨子的人》｜可见性状态重建 v0.3

**项目：**《言说的边界》｜**日期：**2026-10-30  
**状态：**Research-only；PR #26 保持 Draft；不进入公开网站。

## 一、研究判决

本轮把项目从“存档版本差异”推进到**带时间边界的可见性状态重建**。

最重要的新增证据不是再找到一份转载，而是：
1. yyrw.org.cn 的 2020-03-11 首页快照实际包含艾芬采访的直接链接；
2. 此后找到的六份 2020 年首页快照均没有该链接，最晚一份为 2020-11-25；
3. 同一文章页的标题从“吹哨子的人”变成“发哨子的人”，变化被限定在 2020-03-11 北京时间 01:09:54—12:19:23 之间；
4. 中国数字时代披露的据称媒体指令列出同一文章 URL，但其英文说明明确警告：日期可能是指令泄露日期而非签发日期，措辞可能不完全准确，部分指令可能只适用于地方或特定行业。
5. CDT 404文库的“原文”链接指向21join；Wayback在2020-03-12 08:42:23保存了标题为“发哨子的人 | 合传媒”的可读页面。其归一化正文与Terminus完全相同，yyrw正文则有两个短差异区块。

因此，研究可以讨论**不同信息可见性状态如何先后变化**；不能把它写成已证明的指令执行链或标题修改因果调查。

### 两个独立的观察区间

**标题变化：**最后一份旧标题快照为 2020-03-11 01:09:54，第一份新标题快照为 12:19:23，间隔 **11小时09分29秒**。这只是存档观测边界，不是编辑发生的精确时间。

**首页链接状态变化：**最后一次观察到链接为 2020-03-11 03:06:34；第一份之后无链接的快照为 2020-03-12 14:31:01，间隔 **35小时24分27秒**。此后五份 2020 年首页快照也未见链接，最晚至 2020-11-25 22:05:20。

### 首页链接的具体性质

在 03:06:34 的快照中，链接位于 p > li > ul > td 结构中的列表项，页面共有125个链接、11个脚本，正文主体可读取。它证明该文章当时**在首页列表中有直接链接**，但不证明它是首页头条、横幅或置顶推荐。

之后六份快照同样具有125个链接、11个脚本及可读取的 body，但未发现该文章直接链接或标题关键词。这比单纯的“页面打不开”更有信息量，但仍仅代表六个具体存档时点的首页HTML。

## 三、与被披露的媒体管理指令交叉核对

中国数字时代中文页面标注日期为 **2020年3月10日**，列出“涉发哨人，此类报道不上首页，如有请撤下”，并将“吹哨子的人”及其 yyrw.org.cn 文章 URL 列为参考链接。

[中文披露](https://chinadigitaltimes.net/chinese/655981.html)  
[英文披露，2020-12-11发布](https://chinadigitaltimes.net/2020/12/minitrue-diary-march-10-2020-tibet-independence-covid-rent-relief-whistleblower-epidemic-transmission-and-treatments/)

**关键来源限制：** CDT 英文页面明确指出，指令可能通过口头方式传达，因此公开措辞未必精确；部分指令可能由地方机关发出或面向特定行业；页面标注日期也可能是指令泄露日期，而非实际签发日期。中文和英文页面属于同一 CDT 披露链，不是两份独立原始指令。

这改变了对时间线的解释：

- 2020-03-11 03:06:34 的首页快照仍有文章链接，而 CDT 披露的指令日期标签是 3月10日。
- 但我们不知道指令的真实签发时刻、泄露时刻、接收对象、具体适用范围，也没有原始签收记录。
- 因此，这是一项**跨来源的时间张力**，不是“网站明确违抗命令”的证据。
- 3月12日后首页快照不再出现该链接，与后来首页移除相容，但不能证明这是该指令造成的。

## 四、补充来源链：CDT 404文库与 21join 链接

进一步直接读取 CDT 的《〖404文库〗人物｜发哨子的人》页面后，发现它不仅保存了采访正文，还提供了一条新的来源线索：

- 页面显示日期：2020年3月10日。
- CDT 编辑注原文为：“该文原文已被删除 由合传媒备份存档”。
- 页面中标为“原文”的超链接指向：`https://www.21join.com/index.php?a=show&c=index&catid=9&id=2703&m=content`。
- CDT 页面本身保留了采访文本和龚菁琦、金石、尹夕远的署名信息。

这使得来源链可以暂时表示为：

`《人物》原始发布（未取得原始微信字节） → CDT所称合传媒备份 → CDT 404文库再存档`

但 21join.com 的确切角色仍未完全确认。CDT 将其链接标为“原文”，这是可核查的来源归属声明，不是独立真实性认证。直接打开链接时网页工具返回 cache miss；这本身不等于原站服务器不可访问。

**进一步的历史存档核查已经找到一份实际页面：**

- Wayback CDX 对精确 21join URL 返回一条 2020 年记录，HTTP 200、text/html。
- 捕获时间：2020-03-12 00:42:23 UTC，即北京时间 **08:42:23**。
- 页面标题：**“发哨子的人 | 合传媒”**。
- 存档HTML返回 200，抽取后页面正文约 9,376 个字符；采访开头、艾芬姓名、龚菁琦/金石署名以及“合传媒”均可识别。
- 页面元数据还包括关键词“中国、武汉、疫情、吹哨人、艾芬”，description为采访末尾的一段文字；未发现 canonical URL。
- 精确 URL 的 CDX 查询返回一条文章页记录。随后域名级查询返回三条记录：一条文章页、两条 api.php?op=count 的计数端点存档；后两者不是额外文章版本，也不据此推断阅读量。
- [Wayback 21join页面快照](https://web.archive.org/web/20200312004223/http://www.21join.com/index.php?m=content&c=index&a=show&catid=9&id=2703)。

这条记录与 yyrw 首页序列构成一个重要的跨站观察：**3月12日08:42:23，21join/合传媒页面已有可读的采访存档；同日14:31:01，yyrw首页快照已不再包含该采访的直接链接。** 两份存档相隔5小时48分38秒。它说明不同网站/载体的可见性状态并不同步，但不证明21join在14:31仍然实时可访问，也不证明两个站点之间存在协调或因果关系。

### 三份衍生文本的机器比较

现已对以下三个可由CI获取的衍生文本执行同一抽取和归一化流程，每份得到200个句子单元：

| 比较 | 相同单元 | 不同区块 | 结果 |
|---|---:|---:|---|
| Terminus vs 21join/合传媒 | 200/200 | 0 | 归一化正文完全相同 |
| Terminus vs yyrw | 198/200 | 2 | 两个句子单元有差异 |
| yyrw vs 21join/合传媒 | 198/200 | 2 | 同样两个差异 |

相对于 Terminus 与 21join/合传媒，yyrw版本在一个句子单元中少了“艾芬”二字，在另一个句子单元中多出“生康”二字。这里仅报告归一化文本的差异，不推断是编辑、转码、删改还是其他原因。

**来源独立性必须单独处理：** Terminus 与 21join/合传媒的归一化正文完全相同，但这不能说明谁复制谁，也不能证明二者独立。CDT编辑注称备份来自合传媒，21join页面标题也显示“合传媒”，因此21join页面与CDT 404文库应视为同一保存来源链上的相关副本，不能被当作两份独立原始证据。

CDT 404文库页面本身可通过网页检索直接读取，但GitHub Actions请求同一页面返回HTTP 403，所以它没有纳入程序化文本比较。当前三份机器比较对象是 Terminus、yyrw 和 Wayback 21join/合传媒页面；CDT页面作为单独读取的来源说明登记。

### 附带的计数端点：只记录，不解释为读者规模

21join/合传媒文章页的HTML还引用了文章ID为2703的计数端点（api.php?op=count&id=2703&modelid=1）。Wayback保存了两份对应响应：
- 2020-03-12 08:42:23，北京时间：hits=1493，weekdowns=1493，monthdowns=1493，todaydowns=172。
- 2020-03-12 09:02:12，北京时间：hits=1503，weekdowns=1503，monthdowns=1503，todaydowns=182。

两次响应相隔19分49秒。这里仅保留站点返回的原始字段值；字段语义、去重规则和更新机制尚未核实，**不能将其称为独立读者数、真实阅读量或可验证的受众规模**。它不进入本研究的核心结论。


## 五、把“可见”从二元标签改为多维状态

本案例不应使用简单的“文章被删/没有被删”二元变量。至少应分别记录：

| 维度 | 本案例观察 |
|---|---|
| 原始URL可访问性 | 原微信链接的历史快照显示不可查看提示 |
| 衍生正文可访问性 | yyrw、Terminus、21join/合传媒历史副本可读 |
| 首页可发现性 | yyrw首页先有直接链接，后续六份快照没有 |
| 标题框架 | “吹哨子的人”转为“发哨子的人” |
| 历史保存 | Wayback和GitHub保留不同载体的版本 |
| 公众何时知道内部指令 | CDT英文披露于2020-12-11发布；不能倒灌为2020-03-10普通公众已知 |

这组状态可以成为《言说的边界》后续案例的可复用证据框架：**URL可达性、首页可发现性、衍生副本存续、标题框架、历史保存和公共披露时间必须分开测量。**

它也与“六个时钟”方法形成直接连接：事件/指令日期、泄露日期、网页捕获时间、标题版本时间、平台可见性时间和公众披露时间不是同一个时钟。一个日期不能替代另一个日期。

## 六、先行研究与原创性边界

Sun & Wright 已系统研究围绕艾芬采访的 relay activism、微信与 GitHub 传播、创意转发及其流通机制。因此，本项目不主张首次发现“接力传播”或“数字规避”。

本项目更窄的贡献是：
- 逐份检验同一文章URL的历史标题；
- 在首页HTML中定位直接链接及其后续缺失；
- 将原微信不可查看页、衍生正文、首页链接、标题变化和后来的指令披露分开计时；
- 通过可复现CDX脚本与结构化来源账本记录“观察到了什么”以及“仍然不能推出什么”。

这是一项**数字史料学/计算社会科学的微观历史重建**，不是AI/ML实验，也不应被包装成AI安全论文或单纯GitHub贡献。

## 七、停止条件与出版判决

现有证据足以支撑一篇短篇、明确标注不确定性的档案考证草稿；尚不足以支持“某个指令导致某个网站在某一时刻执行了某项审查动作”的因果叙述。

公开前仍需：
1. 独立人类复核两份首页快照、六份后续快照及21join/合传媒页面快照；
2. 复核CDT中文/英文页面、21join链接来源链及指令日期说明；
3. 由作者审阅标题与短引文的版权使用边界；
4. 保留“CDX域名级别补充查询HTTP 503，首页别名覆盖不完全”的限制。

若上述复核通过，建议将其写成《言说的边界》的一篇**短篇数字档案考证**，而不是扩展成大型因果调查。PR #26继续Draft；不新建公开网页，不改动主站，也不合并PR #24。
