# 一篇采访的不同命运：2020年艾芬报道的网页可见性与历史版本

**《言说的边界》｜数字史料考证·供审阅稿 v0.5（2026-11-01）**  
**RESEARCH DRAFT — NOT PUBLISHED; NOT INDEPENDENTLY HUMAN-REVIEWED; NOT A CAUSAL FINDING.**  
基于 PR #26 的冻结证据与成功的限定范围动态复现；本稿未重新认证原《人物》微信的原始发布字节。

## 导语

一篇文章究竟什么时候“消失”？当原始链接不能打开时，当首页不再推荐它时，当标题发生变化时，还是当所有转载都无法找到时？2020年3月艾芬接受《人物》采访后的网页档案提示：这些并不是同一种事件。平台入口、首页发现机制、标题版本和转载文本，可能呈现不同的状态。

本篇不试图还原未经证实的内部决策链，而是研究**公众可见的网页版本留下了哪些可以复核的痕迹**，以及这些痕迹容许我们得出何种有限结论。

## 一、六种不能混为一谈的可见性

至少区分：（1）原始链接内容是否可读；（2）下游副本正文是否可读；（3）首页能否直接发现文章；（4）标题与框架如何呈现；（5）历史存档保留了什么；（6）有关管理指令何时被后来的公众看到。

2020-03-11 06:58:25（北京时间）的一份原《人物》微信 URL 存档显示“此内容因违规无法查看”，但并不包含采访原文。这只能说明**该捕获的页面状态**，不能确定最早失效时刻和具体执行者。

2020-03-10 21:50:52 的 yyrw 文章页历史快照保留采访衍生文本，Terminus 也有同期可读存档。2020-03-12 08:42:23 的 21join/合传媒存档又提供一个衍生版本。原始 URL 不可查看与衍生副本可读并不矛盾，因为观察对象属于不同网站与不同传播载体。

## 二、11小时09分29秒：标题版本的观察边界

在 yyrw 同一文章 URL 的历史记录中，最后一份“吹哨子的人”标题快照的捕获时间为北京时间 **2020-03-11 01:09:54**；首次观察到“发哨子的人”标题的快照时间为 **2020-03-11 12:19:23**。

因此，我们能够给出的是一个**存档观测区间**：旧标题存在于前一捕获时点，新标题存在于后一捕获时点。11小时09分29秒不是网页编辑耗时，更不是可以精确指认的命令执行时间。现有证据无法判定修改者、内部编辑理由或是否由外部要求促成。

此处的“变化”是网页版本事实；“为什么变化”仍是解释问题。

## 三、35小时24分27秒：首页链接状态的观察边界

北京时间 **2020-03-11 03:06:34**，一份 yyrw 首页存档 HTML 中包含指向该文章的直接链接，链接位于普通列表项，零基索引为28，并非已确认的头条或横幅。

**2020-03-12 14:31:01** 的下一份可读首页快照中，不再出现该文章直接链接；随后找到的另外五份2020年首页快照也未包含该链接或其标题关键词。两次关键快照间隔35小时24分27秒。

这证明被捕获的首页 HTML 表现出“有链接—无链接”的状态变化，但不自动证明：（a）链接在此期间始终存在或始终缺席；（b）不存在其他首页别名或动态入口；（c）有人有意“降权”；（d）某条指令导致了上述状态。

## 四、关于据称的首页管理指令：关联，而不是已识别的因果机制

中国数字时代的中文披露页面标注2020年3月10日，并列出限制相关报道进入首页的内容及 yyrw 的同一文章 URL：

https://chinadigitaltimes.net/chinese/655981.html

其英文披露明确提醒，所标日期可能是**泄露日期而非签发日期**；部分文字可能来自口头传达，部分要求可能仅适用于特定地区或行业：

https://chinadigitaltimes.net/2020/12/minitrue-diary-march-10-2020-tibet-independence-covid-rent-relief-whistleblower-epidemic-transmission-and-treatments/

这份披露与 yyrw 首页状态存在值得研究的时间关系，但缺少原始签发、送达、接收、执行日志，无法从“披露指令—后续首页无链接”推导因果。中文和英文披露属于同一来源谱系，不能算成两条独立的原始指令证据。

一个未被确定的可能性是普通首页列表轮替：即使没有任何审查指令，新闻列表也可能随新文章更新而自然移除旧链接。现有快照尚未进行完整的同栏其他新闻轮替对照，因此**“首页链接消失”不能独自诊断审查机制**。这并不取消对宣传与审查制度的批判性研究，只是避免用无法识别的机制替代证据。

## 五、转载副本的相似与来源独立性

冻结的三源文本比对对每份衍生文章分别提取200个规范化句类单元。Terminus 与 21join/合传媒为 **200/200** 相同；yyrw 相对二者各为 **198/200** 相同。差异主要涉及少量短字串，不能据此推定哪一方先行，也不能推定差异的编辑原因。

这类文本一致性具有两种不同含义：它表明衍生副本在观察到的正文层面高度接近，但不能证明三条独立的采集路径。CDT 自述其备份来自合传媒，也不能当作独立的源头认证。

同样，21join 计数端点的 `hits` 值没有经证实的定义，不适合作为真实阅读量或独立读者数。

## 六、方法：将“删除”拆成可观测变量

本研究使用 Wayback CDX 返回的存档记录、实际抓取的 HTML、捕获时间和 SHA256 指纹，结合固定版本的文本规范化比较。取样不是对整个互联网的穷尽搜索，而是对指定 URL、首页入口及若干衍生副本的有限审计。

为了避免伪精确，所有日期都区分：事件所称时间、页面显示日期、存档捕获时间、信息后来公开披露时间。捕获时间不被当作编辑时间；当前网页内容不被当作历史原始版本；访问失败不被当作不存在。

以后的案例应沿用“来源—时间—可见性状态—依据—失效条件—不支持推论”的六元组记录方法。

## 七、本文真正能够支持的结论

1. 指定的历史快照中，原微信页面的可读性状态与若干衍生文章页不同。
2. 指定 yyrw 文章 URL 的标题在两个存档时点之间呈现不同版本。
3. 指定 yyrw 首页快照从存在直接链接变为不包含该链接；这是离散观察，而非连续监测。
4. 据称的管理指令与文章 URL 存在可核对的披露关联，但指令真实性、实际时点、接收与执行关系没有在本研究中被独立重建。
5. “是否存在”、“能否被首页发现”、“以何种标题呈现”是三个不同的历史问题。将它们汇总成单一“被删时间”会丢失重要信息。
