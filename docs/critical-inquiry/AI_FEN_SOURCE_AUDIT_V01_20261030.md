## 1. 决策摘要

**建议继续一轮范围严格限定的版本来源审计；暂不写公开文章。**

本轮确认一个比“文章被删除、网民接力传播”更值得核查的问题：至少两个现存网页承载了《人物》采访的完整或近完整文本，但它们的标题、署名呈现、开篇和版面结构并不完全相同。其中一个页面目前显示日期为 **2020-03-10**，来源栏标注《人物》，同时在页脚标明网站由“中欧国际医院管理中心”主办、版权归“北京中欧国际医院管理技术研究院”；该网站的“关于本站”页又将自身介绍为“中国生命关怀协会医院人文建设专业委员会”网站，并称该协会由国家卫生健康委员会业务主管。**这些是现存网页上的自我描述，不足以单独认证该页面在2020年3月10日已经在线、由哪个主体决定刊载，或为何能够保留。** 国家卫生健康委员会官网的2023年《委直属联系单位和日常管理社会组织名单》确实将“中国生命关怀协会”列入日常管理社会组织，但这只确认协会在该名单中的位置，不证明 yyrw 网站由卫健委直接运营，也不证明该文曾被有意豁免删除。 另一个更强的时间线索来自端点星的 GitHub 仓库：GitHub API 记录到一条已验证签名、添加该档案文件的提交，committer timestamp 为 **2020-03-10 05:23:09 UTC（北京时间13:23:09）**，之后还有三条同日文件更新。这能给出端点星仓库中该副本的提交时间边界，但不是《人物》原始发布的时间，也不能证明 yyrw 页面当日已上线。

已有同行评审研究已直接研究这篇文章的接力传播（Sun & Wright，2023年5月24日 online；2024年卷期），并将其概念化为 *relay activism*，研究范围涉及微信、GitHub、文本分析与参与式观察。因此，本项目不能把“发现网民将文章转成 emoji、摩斯码或其他形式”包装成原创发现。可争取的差异化贡献是：**对仍可访问的文本版本做可复核的来源谱系、逐段差异和时间元数据审计，并检查一个带有医疗人文机构自我定位的网站所保存的文本如何与其他档案版本相互关系。**

### 目前可以支持的判断

1. 《人物》采访在2020年3月10日发布，是多个现存来源共同记载的事件；但本轮没有取得可认证的原始公众号发布记录。
2. 《卫报》2020年3月11日的同期报道记载，《人物》已移除该文，其他中国社交媒体版本也迅速消失，并描述截图及变体传播。它是重要同期报道，但不是平台删除日志或具体命令。
3. 端点星存档页可直接读取，标注2020年3月10日，并注明原文来自《人物》；页面保存采访文本、作者/编辑/摄影署名和图片链接。
4. \`yyrw.org.cn\` 的现存页面可直接读取，显示日期2020年3月10日、来源《人物》、作者“龚菁琦 尹夕远”，以扩展标题刊载采访文本，并在末尾注明转载来源。
5. 两个现存页面在标题、署名展示、开篇和页面结构上有可观察差异；**尚未进行逐段、逐字符的完整差异分析**。
6. Sun 与 Wright 的同行评审文章已研究这次接力传播。论文摘要说明使用文本分析和参与式观察，研究微信及 GitHub；论文注释还指向一份题为“一百零八个版本”的二级资料。该数字不是本项目独立核验的版本数，不能直接当作完整、独立或穷尽的样本量。
7. 我还直接比较了端点星仓库的首个已验证签名提交与同日稍后的版本。当前逐行 LCS 比较检测到的差异集中在 front matter/图片元数据、HTML 包装标签和空白格式；没有检测到被修改的正文行。这个结果只适用于端点星仓库的两个版本，不是端点星与 yyrw 两份副本的完整比较。

## 4. 可发表性判断与新颖性边界

### 已有研究覆盖的内容

- 采访发布后遭删除的同期报道。
- 网民将文章转换为不同文字、语言、编码与格式进行接力传播。
- 通过微信和 GitHub 维持争议性公共表达的机制。

以上不能作为本项目的首创发现。特别是 Sun 与 Wright 已发表同行评审研究，研究范围直接覆盖这次事件。

### 仍可能形成独立贡献的内容

- **版本谱系而非变体罗列：** 哪些页面保存同一段落，哪些只重排标题、署名、图片或段落；每个版本最早可证实的时间是什么。
- **档案存续的机构环境：** yyrw.org.cn 的页面自我描述、页脚主办方与转载正文之间的关系，及其在历史时间上的可认证程度。
- **删除证据的精确范围：** “原公众号页面被移除”“某个转载被移除”“所有大陆媒体均删除”“全网删除”是不同命题，须各自找来源，不能互相替代。
- **档案缺失如何塑造历史认识：** 当原始平台记录缺失时，后来的可读版本能证明什么、不能证明什么。

### 继续 / 停止门槛

**继续下一轮定点审计**，但只有满足以下条件之一，才值得发展为独立文章：

- 找到具有可验证时间的历史快照，使某一版本的“最迟存在时间”或版本演化可以收窄；
- 完成可复现的逐段版本差异，并发现既有论文没有处理、且能改变对存档路径的解释；
- 独立核实 yyrw.org.cn 在2020年转载的时间与机构关系，从而得到一个可被证据支持、而不是猜测的存档例外案例。

若只有现存转载页、一般性删除报道和既有的接力传播研究，**应停止将它扩展成独立实证论文**；可把来源审计作为《六个时钟》的后续案例或方法附录，而不是为追求新专题强行制造原创性。

## 5. 与《言说的边界》研究议程的连接

本案例直接延伸《历史证据的六个时钟》的第六只时钟：研究者在多年后发现档案版本差异的时间。它也复用上海/李文亮研究中已经建立的证据纪律：

- 原始言说、公开定性、强制行为、后续政策和回溯性档案必须分开；
- 页面可访问性、页面显示日期、服务器发布时间和历史快照不是同一证据；
- 来源数量不等于独立来源数量；
- 观察到版本差异不等于证明政治审查指令；
- 批判性分析必须明确记录权力关系和证据缺口，而不是以中性措辞抹去权力不对称。

**当前建议：先完成来源谱系与版本差异；在完成前不新建公开文章页，不把本审计并入网站主分支。**
