# 《解释的边界》×《谁有权定义谣言？》
## 上海2022｜3月26日发布会“不能封城”段落的版本审计 v0.5

**状态：研究草稿，未经第二名人类审核人复核。**  
审计日期：2026-10-29。事件日期：2022-03-26。  
此文件归属PR #21，不发布到已上线个人网站。

### 核心发现

在上海市政府**现存**2022年3月26日发布会问答实录中，吴凡介绍了继续开展“重点区域+非重点区域”筛查的理由。该文稿在解释“病毒传播快”和“上海城市特点”之后，转向对市民认真检测的呼吁。

但同日媒体报道还包含一段关于**为什么不采取让上海全城同时停摆三、五天或一周的方式**的回应，理由涉及上海对全国乃至全球经济及航运体系的作用。

这是**同一场公开活动的不同文本版本**。它能够被直接复核，但不能直接证明政府实录“后来删除”了该段，更不能因此断言存在特定的审查命令。

**逐项比较：**

- **共同内容：** 吴凡介绍病毒传播快、上海城市特点及对全市检测的安排。
- **现存政府实录：** 叙述“城市特点”后直接转入提醒居民认真采样，没有完整呈现“全城封3/5/7天不可行”的国际经济理由。
- **三份同期媒体报道：** 明确记录上述答复，尤其是全球经济与航运方面的解释。
- **目前可以断言：** 所能看到的官方文字版本与多家同期媒体记录存在可定位的内容缺口。
- **不能断言：** 删除发生的具体时刻、文本编辑者、政治指令、意图、传播范围、公众是否实际收到不同版本。

严格来说，**“现存稿遗漏某段”不是“后来撤下某段”**。后一种历史断言必须取得早期网页快照、内容版本差异或编辑记录。

### 第三组：这段话与3月27日新措施有没有逻辑矛盾？

关键是精确界定两种政策：

- **3月26日讲话:** 讨论让全城**同一时间停摆**三、五天或一周的成本；同期表述倾向分区、分类筛查。
- **3月27日公告:** 分批、分区域开展核酸筛查与封控，两批原计划各四天。
- **3月31日通告:** 对部分浦东地区公布更长的分级管理。
- **4月4日公告:** 全市继续封控管理直至检测、复核及后续研判完成。

这说明公共政策解释和实践很快变化，却不能只用“3月26日反对全城停摆、3月27日分区封控”就证明同一命题逻辑矛盾。它更适合检验公开讲话是否**清楚界定了“全城停摆”与“分区封控”的政策边界**，以及后续治理措施如何影响听众对原先解释的理解。

### 本案例形成的三个可独立发表的研究问题

1. **事实定性：** 政府怎样解释对未来政策预测的“不实”标签？何时把预测内容、消息来源与传播行为混在同一公共断言里？
2. **解释选择：** 新闻发布会保存的公共文字记录为什么只保留部分论证？是否应有完整录音、版本和修改说明，便于公民检验？
3. **权力可问责性：** 当错误信息认定与刑事立案连在一起，公共部门需要给出什么层次的可检查证据、程序和纠错渠道？

它们相互关联，但不能用任何一项的资料直接“证明”另一项的结论。

### 可直接证实的结论／必须保持未定的结论

**可证实：** 现存官方问答实录与三份同期媒体报道存在文字层面的内容差异；3月23日警方立案的新闻时点至少可追溯到17:59:14；3月27日之后政策仍有正式调整。

**尚不能证实：** 官方于某天删改3月26日讲话；官方因政治理由刻意隐藏讲话；两名立案对象后来被起诉、定罪或撤案；匿名Y先生就是被立案者；早期传言原帖经过认证；由这一事件引发了群体性的自我审查。

### 下一项会改变结论的材料

- 3月26日发布会的完整、可独立读取的原始影音；或者有可信时间戳的当天政府网页捕获。
- 两种“七天”“四天”网传消息的原始微信消息、截图来源链与创建/转发记录。
- 3月23日两名被立案人员的后续检察机关决定、裁判文书或权威更正。
- 能区分政策制定机关在3月22日至27日不同日期信息状态的正式材料。
